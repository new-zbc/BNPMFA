The folder contains the scripts and results of three applications in the manuscript. 

## DLPFC data

The ''DLPFCdata" folder contains the results of slices 151507 to slices 151672. In the folder of each slice, we provided the following files:

* Data file stored in a ``SingleCellExperiment`` object
* Scripts of BNPMFA  and competing methods
* The spatial domains detected by all methods
* A csv file "summary_metric.csv" providing spatial domain identification performance of all these methods.  

## STARmap

The "STARmap" folder contains the results of slice BZ5, BZ9, and BZ14. In the folder of each slice, we provided the following files:

* Data file stored in a ``SingleCellExperiment`` object
* Scripts of BNPMFA  and competing methods
* The spatial domains detected by all  methods
* Summary metrics (ARI, AMI, NMI) of spatial domain identification performance for all methods

## VisiumHD

The folder "VisiumHD" contains the results of the CRC sample. We provided the following files:

* Data file stored in a ``SingleCellExperiment`` object
* Scripts of BNPMFA  and competing methods
* The spatial domains detected by all methods
