This folder contains the simulation results for varying number of genes. We provided the following files:

* The script to generate the simulated with varying number of genes -> "sim3Datagenerator2.R"
* The scripts of BNPMFA and competing methods -> "script" folder
* The summary of spatial domain identification results of each case from "p_2000" to "p_25000"
* The scripts to generate figures of simulations -> "plot folder"
