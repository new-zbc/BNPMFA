## Data generator

In each scenario folder, we provide the code to generate the simulated data.

## Run different methods

In the folder "script", we provide the code to run the simulated results. 

## Result

In each scenario folder, we provide the "summary" folder to report the performance of all methods. 

In the folder "Model_compare", we provide the performance of Dirichlet process (DP), Pitman-Yor (PY), and mixture-of-finite-mixtures (MFM) version of BNPMFA. 

## Plot

To show the box plot of clustering performance measurements, we provide the plot functions for simulated results, including "plot_ARI.R", "plot_AMI.R", and "plot_NMI.R".
